# Kids A-Z 答案助手

一个用于 Kids A-Z / Raz-Kids 学生端的 Chrome/Edge MV3 扩展，提供测验答案、页面高亮、学生自动登录、一键完成和一本书的下载功能。

> 非官方项目，与 Kids A-Z / Learning A-Z 无关联。仅供个人学习和研究使用；使用前请自行确认是否符合你所在学校或服务条款的要求。

## 功能

- **测验答案**：拦截 `get_quiz_info` 接口，在扩展弹窗显示答案速记串和逐题选项。
- **页面高亮**：在页面上标记正确选项（可选）。
- **学生自动登录**：老师用户名 → 学生图标 → 学生密码。
- **一键完成**：按配置自动完成 Listen / Read / Quiz，默认读 + 题；AA 级书自动跳过 quiz。
- **书籍下载**：
  - 每页 JPG（默认）
  - 页图 ZIP
  - 页图 PDF
  - 朗读音频（分段 MP3，或合并 WAV）
  - 合并音频 + PDF 打包为一个 ZIP
  - 当前页单页下载
- **总开关 + 分类设置**：设置页以独立标签页打开，答题助手 / 阅读 / 一键完成 / 下载 / 学生自动登录分别配置。

## 安装

1. 下载或克隆本仓库。
2. 打开 Edge/Chrome 的 `edge://extensions`（Chrome 为 `chrome://extensions`）。
3. 开启“开发人员模式”。
4. 点击“加载已解压的扩展程序”，选择本仓库根目录。
5. 点扩展图标右上角 ⚙，或右键图标 → “选项”，在独立标签页中配置。

修改代码后需要在扩展页点“重新加载”，再刷新 Kids A-Z 页面；content script 只在导航时注入。

## 使用

### 答案

打开 Kids A-Z 测验页面，等待接口返回，点击扩展图标查看答案。

### 一键完成

在 Level Up / Reading Room 书卡上点击“一键完成”；或在扩展弹窗中选择“一键完成一本书”。默认执行 Read + Quiz，可在设置页调整步骤。

### 下载

在书卡上点击“下载”；或在扩展弹窗中选择“下载一本书”。默认只下载每页 JPG，ZIP / PDF / 音频 / 打包 / 单页均为独立开关。

## 权限

- `storage`：保存设置、答案和任务状态。
- `activeTab`：读取当前标签页信息。
- `downloads`：写入下载文件。
- `*://www.kidsa-z.com/*`：页内脚本和接口。
- `*://mi.content.kidsa-z.com/*`：页图和朗读音频资源（页面直接 fetch 会被 CORS 拒绝，必须由后台抓取）。

## 安全与隐私

- **学生密码以明文保存在本机 `chrome.storage.local`**（扩展存储）。不要在公用电脑上使用；如介意，可改用浏览器密码管理器或 Windows 凭据管理器等外部方案。
- 扩展不会上传密码、Cookie 或学生信息到任何第三方服务器。
- 答案、书目、下载均来自当前已登录的 Kids A-Z 会话。
- 测试/开发时不要在仓库或日志中写入真实密码、Cookie、学生姓名。

## 已知限制

- 页面结构依赖 Kids A-Z 当前版本；站点改版后选择器/接口可能失效，需同步更新 `API.md` 与代码。
- Listen 的完成判定仍是 best-effort，默认关闭。
- Quiz 含开放题/构造题时无法自动完成，会中止并报告。
- 服务端会校验阅读时长；客户端补足时长不保证在所有书上通过。默认补足 10 秒/页。
- PDF 仅按 RGB JPEG 嵌入；灰度或非 JPEG 页图可能显示异常。
- 合并音频输出 WAV（不是 MP3），文件可能较大；逐段下载才是 MP3。
- 逐页下载多文件时，浏览器可能询问是否允许下载多个文件。
- 下载文件名中的空格可能被 Chrome 替换为下划线。
- 没有自动化测试；仅提供语法检查。

## 开发

没有构建步骤、依赖或打包器。源码是平铺的静态文件。

```powershell
Get-ChildItem *.js | ForEach-Object { node --check $_.Name }
```

主要文件：

- `manifest.json`：MV3 配置。
- `inject.js`：页面主世界，拦截测验接口、执行阅读/听力自动化。
- `content.js`：隔离世界，处理答案和阅读设置。
- `auto-login.js`：学生登录流程。
- `auto-complete.js`：书卡按钮、弹窗书目、Quiz 自动化。
- `background.js`：任务调度、资源抓取、下载写入。
- `download.js`：页图/PDF/ZIP/音频/单页下载。
- `popup.*` / `options.*`：弹窗和设置页。

更详细的接口、路由、页面控件和实测记录见 [`API.md`](API.md)；开发约束见 [`AGENTS.md`](AGENTS.md)。
